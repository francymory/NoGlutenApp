It's a user-friendly mobile android application designed for the object oriented exam. It offers a wide variety of gluten-free recipes. Users can browse dishes by cuisine type (e.g., Italian, Mexican, Chinese) or by meal category (breakfast, lunch, dinner) or other types of intolerance (e.g. lactose free, soy free). Each recipe provides detailed ingredients and instructions, making it easier for people with gluten intolerance—or anyone seeking a healthier lifestyle—to cook safely and deliciously.
